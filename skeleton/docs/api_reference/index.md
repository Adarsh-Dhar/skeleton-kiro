# TRIALFORGE API reference

_Generated by `scripts/gen_api_reference.py` for trialforge 0.2.0 (API version 1). Do not edit by hand._

Everything below is importable from the top-level `trialforge` package; those names are the stable public API.

## Models

### `ExperimentSpec`

Complete, validated definition of an experiment: factors, objectives, input/output constraints, measurement definitions, derived metrics, design method/options, adapter name, execution policy, budget and seed.

Fields: `schema_version`, `experiment_id`, `name`, `description`, `hypothesis`, `factors`, `objectives`, `constraints`, `measurement_definitions`, `derived_metrics`, `design_method`, `design_options`, `adapter_name`, `execution`, `run_budget`, `random_seed`, `metadata`, `created_at`

### `Factor`

An experimental variable.

Fields: `name`, `factor_type`, `values`, `lower`, `upper`, `unit`, `default`, `role`, `validation_rule`

### `Objective`

Optimisation goal for one metric. `function` optionally names a registered objective plugin computing the value from run outcomes.

Fields: `metric`, `direction`, `target`, `weight`, `priority`, `function`

### `Constraint`

Restriction on a factor (`input`) or on a measured outcome (`output`).

Fields: `metric`, `kind`, `minimum`, `maximum`, `equals`, `allowed_values`, `function`, `description`, `validator`

### `MeasurementDefinition`

Declares a metric: unit, type, expected range, aggregation, time-series settings, outlier method and registered transformations.

Fields: `metric`, `unit`, `data_type`, `expected_min`, `expected_max`, `aggregation`, `required`, `time_series`, `sampling_interval_seconds`, `outlier_method`, `transformations`, `description`

### `DerivedMetric`

A per-run metric computed from other metrics' processed values.

Fields: `name`, `unit`, `expression`, `function`, `description`

### `ExecutionPolicy`

Per-experiment execution behaviour.

Fields: `max_retries`, `retry_delay_seconds`, `max_concurrency`, `run_timeout_seconds`, `recovery`

### `Measurement`

A single raw or adapter-provided observation.

Fields: `measurement_id`, `run_id`, `metric`, `value`, `unit`, `timestamp`, `quality_flags`, `raw_value`, `raw_unit`, `source`, `channel`, `metadata`

### `ProcessedMeasurement`

Aggregated/derived value for one run and metric with source measurement ids, quality flags and transformation history.

Fields: `processed_id`, `run_id`, `metric`, `value`, `unit`, `timestamp`, `source_measurement_ids`, `quality_flags`, `transformations`, `window_start`, `window_end`, `derived`

### `MeasurementTransformation`

Audit record of one operation (unit conversion, transformation, aggregation, derivation) applied to measurements.

Fields: `transformation_id`, `operation`, `input_measurement_ids`, `output_measurement_id`, `parameters`, `timestamp`

### `Run`

One experimental run: configuration, lifecycle status and history, raw and processed measurements, attempts and block assignment.

Fields: `run_id`, `experiment_id`, `configuration`, `order`, `status`, `adapter_name`, `adapter_handle`, `measurements`, `processed_measurements`, `error`, `started_at`, `completed_at`, `metadata`, `block`, `coded`, `replicate`, `attempts`, `idempotency_key`, `history`

### `RunStatus`

Run lifecycle states; see `RUN_TRANSITIONS` for legal moves.

### `DesignPlan`

A generated design: runs with configurations, randomisation, block variables, seed and design metadata (defining relations, alias structure, resolution where applicable).

Fields: `experiment_id`, `method`, `runs`, `control_configuration`, `random_seed`, `metadata`, `block_variables`, `randomization`, `design_info`, `treatment_factors`

### `ExperimentResult`

A specification, its design plan and the current state of all runs.

Fields: `spec`, `plan`, `runs`, `status`, `created_at`

### `ExperimentStatus`

Experiment lifecycle states; see `EXPERIMENT_TRANSITIONS` for legal moves.

### `AnalysisResult`

Output of :meth:`AnalysisEngine.analyse`. Every estimate lists the runs it used; excluded runs carry reasons; warnings state statistical limitations.

Fields: `experiment_id`, `descriptive`, `effects`, `factor_effects`, `pareto_run_ids`, `method`, `assumptions`, `limitations`, `algorithm`, `algorithm_version`, `created_at`, `input_run_ids`, `excluded_runs`, `sample_sizes`, `warnings`, `interactions`, `anova`, `regression`, `feasible_run_ids`, `infeasible_runs`, `tradeoffs`, `best_run_id`, `outlier_flags`, `factor_effects_by_metric`, `main_effects`, `parameters`

### `EffectEstimate`

A treatment/control or factor-level comparison for one metric.

Fields: `metric`, `control_mean`, `treatment_mean`, `mean_difference`, `relative_change_percent`, `sample_size_control`, `sample_size_treatment`, `standard_error`, `confidence_interval_95`, `assumptions`, `limitations`, `comparison_type`, `factor`, `level`, `control_level`, `differing_factors`, `treatment_configuration`, `control_configuration`, `control_run_ids`, `treatment_run_ids`, `degrees_of_freedom`, `t_statistic`, `p_value`, `effect_size`, `effect_size_type`, `ci_method`, `bootstrap_ci_95`, `evidence`, `p_value_holm`, `n_comparisons_in_family`, `standardized_note`, `warnings`

### `InteractionEffect`

Two-factor interaction for one metric: difference-of-differences estimate plus ANOVA F test where the design supports it.

Fields: `metric`, `factors`, `estimate`, `description`, `f_statistic`, `p_value`, `degrees_of_freedom`, `run_ids`, `warnings`

### `AnovaTable`

ANOVA table (one-way per factor, or Type II factorial) for one metric, with residual degrees of freedom and warnings.

Fields: `metric`, `kind`, `factor`, `rows`, `residual_df`, `n_observations`, `run_ids`, `sum_squares_type`, `warnings`

### `RegressionModel`

OLS model for one metric with coefficients, fit statistics, coding description, diagnostics and warnings.

Fields: `metric`, `terms`, `coefficients`, `n_observations`, `n_parameters`, `residual_df`, `r_squared`, `adjusted_r_squared`, `residual_std_error`, `f_statistic`, `f_p_value`, `diagnostics`, `coding`, `run_ids`, `warnings`

### `Recommendation`

A proposed next configuration.

Fields: `configuration`, `rationale`, `expected_improvement`, `uncertainty`, `rejected`, `strategy`, `prediction_kind`, `objective`, `predicted_value`, `prediction_std`, `heuristic_score`, `feasible`, `predicted_feasibility_probability`, `constraint_evaluation`, `remaining_budget`, `created_at`, `experiment_id`

### `StopDecision`

Result of evaluating stopping rules: whether to stop, the reason and detail.

Fields: `stop`, `reason`, `detail`

### `ExperimentReport`

Versioned experiment report (see `report_version`): definition, design, runs, quality, statistics, optimisation history, limitations and reproducibility metadata.

Fields: `experiment_id`, `name`, `objective`, `hypothesis`, `variables`, `design_method`, `planned_runs`, `completed_runs`, `failed_runs`, `invalid_runs`, `measurement_summaries`, `treatment_effects`, `best_configuration`, `constraint_violations`, `optimisation_history`, `suggested_next_experiment`, `limitations`, `report_version`, `generated_at`, `description`, `constraints`, `design_info`, `planned_run_details`, `failed_run_details`, `invalid_measurements`, `interactions`, `anova`, `regression`, `model_diagnostics`, `best_observed_run_id`, `pareto_run_ids`, `infeasible_runs`, `data_quality_issues`, `analysis_warnings`, `reproducibility`, `extensions`

## Design

### `ExperimentDesigner`

Generate :class:`DesignPlan` objects from an :class:`ExperimentSpec`.

- `control_for(spec: 'ExperimentSpec') -> 'dict[str, Any]'`: Control configuration for `spec`: each factor's default, else its first candidate level.
- `check(spec: 'ExperimentSpec', method: 'str | None' = None) -> 'list[str]'`: Return a list of problems preventing `method` for `spec` (empty = compatible).
- `design(spec: 'ExperimentSpec', method: 'str | None' = None) -> 'DesignPlan'`: Generate a reproducible :class:`DesignPlan` using `method` (default `spec.design_method`). Raises DesignError for incompatible methods, exceeded budgets or infeasible designs.
- `sequential(spec: 'ExperimentSpec', result: 'ExperimentResult | None', configurations: 'list[dict[str, Any]]', *, iteration: 'int' = 1, source: 'str' = 'optimizer') -> 'DesignPlan'`: Create a plan of *new* runs appended after the existing ones.

## Execution

### `ExperimentService`

Facade for the experiment lifecycle.

- `attach_spec(spec: 'ExperimentSpec') -> 'None'`: Provide the original spec object (with callables) for an experiment; restores validators lost on reload.
- `get_spec(experiment_id: 'str') -> 'ExperimentSpec'`: Retrieve the specification: attached object first, then the repository. Never a hidden cache.
- `validate(spec: 'ExperimentSpec') -> 'ExperimentSpec'`: Validate design compatibility, plugin references and (if resolvable) the adapter. Raises ValidationError.
- `design(spec: 'ExperimentSpec', method: 'str | None' = None) -> 'DesignPlan'`: Validate, design and persist an experiment. Re-designing an existing experiment returns its stored plan.
- `async run(spec: 'ExperimentSpec', method: 'str | None' = None) -> 'ExperimentResult'`: Design (or reuse the stored design) and execute all pending runs.
- `async execute(plan: 'DesignPlan', spec: 'ExperimentSpec | None' = None) -> 'ExperimentResult'`: Execute QUEUED runs of `plan`. Safe to call repeatedly: finished runs are never re-executed.
- `async run_pending(experiment_id: 'str') -> 'ExperimentResult'`: Execute whatever is still queued for a stored experiment (e.g. after restart or retry).
- `async collect_pending(experiment_id: 'str') -> 'ExperimentResult'`: Ask the adapter for measurements of runs in WAITING_FOR_MEASUREMENTS.
- `async ingest_measurements(experiment_id: 'str', run_id: 'str', measurements: 'list[Measurement]') -> 'Run'`: Attach externally obtained measurements (CSV import, manual entry) and complete the run.
- `async cancel(experiment_id: 'str', run_id: 'str | None' = None) -> 'ExperimentResult'`: Cancel one run or all non-terminal runs. Idempotent.
- `retry_run(experiment_id: 'str', run_id: 'str') -> 'Run'`: Explicitly re-queue a FAILED run (a failed run never retries implicitly).
- `async recover(experiment_id: 'str | None' = None) -> 'list[dict[str, Any]]'`: Resolve runs interrupted by a restart according to adapter capabilities and policy.
- `analyse(result: 'ExperimentResult', **kwargs: 'Any') -> 'AnalysisResult'`: Analyse a result; the analysis is persisted for reproducibility and history.
- `optimise(spec: 'ExperimentSpec', result: 'ExperimentResult | AnalysisResult | None' = None, *, count: 'int' = 1, method: 'str' = 'sequential') -> 'list[Recommendation]'`: Recommend next configurations using stored results (loaded from the repository when `result` is omitted).
- `add_runs(experiment_id: 'str', configurations: 'list[dict[str, Any]]', *, iteration: 'int' = 1, source: 'str' = 'optimizer') -> 'list[Run]'`: Append sequential runs (validated, budget-checked, persisted as QUEUED).
- `async run_sequential(experiment_id: 'str', *, iterations: 'int' = 5, batch_size: 'int' = 1, method: 'str' = 'bayesian', criteria: 'StoppingCriteria | None' = None) -> 'tuple[ExperimentResult, StopDecision]'`: Optimise loop: stop-check -> suggest -> add runs -> execute -> repeat. Returns final result and stop reason.
- `report(result: 'ExperimentResult', analysis: 'AnalysisResult | None' = None) -> 'ExperimentReport'`: Build (and persist) a versioned report.
- `history(experiment_id: 'str')`: Read-only history view for a stored experiment.
- `get(experiment_id: 'str') -> 'ExperimentResult'`: Load the current persisted ExperimentResult (with the attached spec object if one was provided).
- `list_experiments() -> 'list[str]'`: IDs of all persisted experiments.

### `LocalBackgroundRunner`

Run experiments as asyncio tasks inside the current event loop.

- `submit(experiment_id: 'str') -> 'asyncio.Task'`: Start executing pending runs; returns immediately. Re-submitting a running experiment is a no-op.
- `is_running(experiment_id: 'str') -> 'bool'`: True while a submitted experiment's task is still executing.
- `async wait(experiment_id: 'str') -> 'ExperimentResult'`: Await a submitted experiment and return its result.
- `async cancel(experiment_id: 'str') -> 'ExperimentResult'`: Request cancellation through the service (marks runs CANCELLED), then await the task.
- `async shutdown() -> 'None'`: Cancel unfinished tasks. Persisted state stays consistent; use `service.recover()` after restart.

### `EventBus`

Subscribers never break the engine: handler exceptions are logged and swallowed.

- `subscribe(prefix: 'str', handler: 'Callable[[Event], None]') -> 'None'`: Subscribe `handler` to events whose name starts with `prefix` ('' = all).
- `publish(event: 'Event') -> 'None'`: Deliver `event` to matching subscribers; handler exceptions are logged and never propagate.

### `Event`

A lifecycle event, e.g. `run.completed`.

## Adapters

### `ExperimentAdapter`

Structural protocol every adapter implements (see the adapter development guide).

- `async validate(config: 'dict[str, Any]') -> 'None'`: Raise (preferably AdapterError) if `config` cannot be executed; return None when acceptable.
- `async prepare(context: 'ExecutionContext') -> 'None'`: Receive the run context before `execute` (used by adapters without `execute_run`).
- `async execute(config: 'dict[str, Any]') -> 'ExecutionResponse'`: Run the configuration. Return `completed=True` with measurements, or `completed=False` with a handle.
- `async collect_result(run_id: 'str') -> 'MeasurementResponse'`: Return measurements of a delayed run; `completed=False` while they are not yet available.
- `async cancel(run_id: 'str') -> 'None'`: Best-effort cancellation of an in-flight run.

### `AdapterMetadata`

Identity and documentation of an adapter.

### `AdapterCapabilities`

What the adapter can do; the engine adapts its behaviour to these.

### `AdapterRegistry`

Explicit registry: no implicit imports or dynamic code execution.

- `register(adapter: 'ExperimentAdapter', *, name: 'str | None' = None, replace: 'bool' = False) -> 'None'`: Register `adapter` under `name` (default `adapter.metadata.name`).
- `unregister(name: 'str') -> 'None'`: Remove an adapter by name (no error if absent).
- `get(name: 'str') -> 'ExperimentAdapter'`: Return the adapter registered as `name`; raises KeyError if unknown.
- `names() -> 'list[str]'`: Registered adapter names in registration order.
- `list() -> 'list[AdapterMetadata]'`: Metadata of every registered adapter.
- `select(spec: 'ExperimentSpec | None' = None, *, name: 'str | None' = None) -> 'tuple[str, ExperimentAdapter]'`: Pick the adapter: explicit `name` > `spec.adapter_name` > sole registered adapter.
- `required_capabilities(spec: 'ExperimentSpec') -> 'list[str]'`: Capabilities the experiment needs from its adapter.
- `check_capabilities(adapter: 'ExperimentAdapter', spec: 'ExperimentSpec') -> 'list[str]'`: Raise CapabilityError for hard requirements; return non-fatal notes.
- `input_schema(name: 'str') -> 'dict[str, Any] | None'`: The declared input schema of adapter `name` (None if it declares none).
- `async ensure_available(name: 'str') -> 'None'`: Await the adapter's optional `available()` check; raises AdapterUnavailableError if it reports False.
- `async start(name: 'str') -> 'None'`: Run the adapter's optional `startup()` hook once.
- `async shutdown_all() -> 'None'`: Run the optional `shutdown()` hook of every started adapter.

### `ExecutionContext`

Everything an adapter receives for one run: ids, configuration, attempt number, idempotency key, seed and metadata (including `requested_metrics`).

Fields: `experiment_id`, `run_id`, `configuration`, `metadata`, `adapter_name`, `attempt`, `idempotency_key`, `random_seed`

### `ExecutionResponse`

Adapter result of starting a run: either completed with measurements, or incomplete with a handle for delayed collection.

Fields: `completed`, `measurements`, `handle`, `metadata`

### `MeasurementResponse`

Adapter result of `collect_result`: completed flag and any measurements received so far.

Fields: `completed`, `measurements`, `metadata`

### `ExecutionStatusResponse`

Result of `adapter.status(handle)`.

Fields: `state`, `detail`

### `schema_from_spec(spec: 'ExperimentSpec') -> 'dict[str, Any]'`

Derive a simple input schema ({factor: {type, min/max or choices, unit}}).

### `check_config_against_schema(config: 'dict[str, Any]', schema: 'dict[str, Any]') -> 'list[str]'`

Return a list of schema violations (empty = valid). Schema format as :func:`schema_from_spec`.

## Measurements

### `MeasurementEngine`

Validate, convert, aggregate and derive measurements for one experiment.

- `assess(measurements: 'Iterable[Measurement]', run_id: 'str') -> 'tuple[list[Measurement], list[Measurement], list[str]]'`: Return `(valid, assessed, warnings)`; never mutates the inputs.
- `validate(measurements: 'Iterable[Measurement]', run_id: 'str') -> 'tuple[list[Measurement], list[str]]'`: Compatibility helper returning valid assessed copies and quality warnings.
- `quality_report(assessed: 'Iterable[Measurement]') -> 'dict[str, Any]'`: Counts per quality status plus metrics with no usable data.
- `process(assessed: 'Iterable[Measurement]', run_id: 'str') -> 'list[ProcessedMeasurement]'`: Aggregate usable samples per metric and compute derived metrics.
- `aggregate_windows(assessed: 'Iterable[Measurement]', run_id: 'str', metric: 'str', *, window_seconds: 'float', aggregation: 'str' = 'mean', channel: 'str | None' = None, origin: 'datetime | None' = None) -> 'list[ProcessedMeasurement]'`: Tumbling-window aggregation of usable samples of `metric`.
- `resample(assessed: 'Iterable[Measurement]', metric: 'str', *, interval_seconds: 'float', channel: 'str | None' = None) -> 'list[Measurement]'`: Linearly interpolate usable samples onto a regular grid.

### `StreamingWindowAggregator`

Incremental tumbling-window aggregation with allowed lateness.

- `push(m: 'Measurement') -> 'None'`: Add a sample; samples for already emitted windows are kept as late arrivals.
- `emit(now: 'datetime') -> 'list[ProcessedMeasurement]'`: Return processed measurements for windows closed as of `now` (each window is emitted once).

### `UnitRegistry`

Unit lookup and conversion. Extend with :meth:`register`.

- `register(dimension: 'str', unit: 'str', scale: 'float', offset: 'float' = 0.0) -> 'None'`: Add a unit (`base = value * scale + offset`) to a dimension.
- `canonical(unit: 'str') -> 'tuple[str, str] | None'`: Return `(dimension, canonical_unit)` or None for unknown units.
- `same_unit(a: 'str', b: 'str') -> 'bool'`: True if two unit strings denote the same unit (identical or aliases).
- `compatible(a: 'str', b: 'str') -> 'bool'`: True when a value in `a` can be converted to `b`.
- `convert(value: 'float', from_unit: 'str', to_unit: 'str') -> 'float'`: Convert `value`; raise ValidationError for incompatible/unknown units.

### `convert(value: 'float', from_unit: 'str', to_unit: 'str') -> 'float'`

Convert using the default registry.

### `make_series(run_id: 'str', metric: 'str', unit: 'str', timestamps: 'list[datetime]', values: 'list[Any]', *, channel: 'str | None' = None, source: 'str | None' = None, metadata: 'dict[str, Any] | None' = None) -> 'list[Measurement]'`

Build time-series `Measurement` records with sample indices and provenance.

## Analysis

### `AnalysisEngine`

Descriptive statistics, comparisons, ANOVA, regression, interactions and Pareto analysis.

- `analyse(result: 'ExperimentResult', *, alpha: 'float | None' = None, bootstrap: 'bool | None' = None, seed: 'int | None' = None) -> 'AnalysisResult'`: Analyse an ExperimentResult: descriptive statistics, per-treatment and per-factor comparisons, ANOVA, regression, interactions and constraint-aware Pareto analysis. Returns an AnalysisResult recording inputs, exclusions, assumptions and warnings.

## Optimisation

### `Optimizer`

Generate the next configurations to run.

- `suggest(spec: 'ExperimentSpec', result: 'ExperimentResult', *, count: 'int' = 1, method: 'str' = 'sequential') -> 'list[Recommendation]'`: Recommend up to `count` unseen, input-feasible configurations using `method` (grid, random, bayesian/sequential, heuristic, optuna or a registered plugin). Returns [] when the budget is exhausted.
- `should_stop(spec: 'ExperimentSpec', result: 'ExperimentResult', criteria: 'StoppingCriteria', *, iteration: 'int' = 0, candidates_available: 'bool' = True) -> 'StopDecision'`: Evaluate stopping rules in priority order: cancel, target, budget, threshold, iterations, stagnation.

### `StoppingCriteria`

Stopping rules evaluated by :meth:`Optimizer.should_stop`.

### `OptimizerContext`

Everything an optimizer plugin needs.

## Persistence and history

### `SQLiteExperimentRepository`

Durable repository. `url` is any SQLAlchemy URL; default is a local SQLite file.

- `in_memory(cls) -> 'SQLiteExperimentRepository'`: Ephemeral repository (lost when the process exits).
- `schema_version() -> 'int'`: Current schema version stored in the database (0 if uninitialised).
- `migrate() -> 'None'`: Bring the database to `SCHEMA_VERSION`; imports legacy 0.1 snapshot databases.
- `save_experiment(spec: 'ExperimentSpec', status: 'ExperimentStatus | None' = None) -> 'None'`: Upsert a specification. Raises if the id exists with a *different* spec hash and runs exist.
- `get_spec(experiment_id: 'str') -> 'ExperimentSpec'`: Load a specification (callable validators are not restored; see module docs).
- `has_experiment(experiment_id: 'str') -> 'bool'`: True if an experiment with this id is stored.
- `get_status(experiment_id: 'str') -> 'ExperimentStatus'`: Current experiment status.
- `set_status(experiment_id: 'str', status: 'ExperimentStatus', reason: 'str' = '') -> 'None'`: Persist an experiment status change and log it.
- `list_ids() -> 'list[str]'`: IDs of all stored experiments, sorted.
- `save_plan(plan: 'DesignPlan') -> 'None'`: Upsert the design plan (run measurements are stored separately).
- `get_plan(experiment_id: 'str') -> 'DesignPlan'`: Load the stored design plan; raises KeyError if none.
- `save_runs(runs: 'list[Run]', experiment_status: 'ExperimentStatus | None' = None) -> 'None'`: Atomically persist runs with their measurements (and optionally the experiment status).
- `save_run(run: 'Run', experiment_status: 'ExperimentStatus | None' = None) -> 'None'`: Atomically persist one run with its measurements.
- `get_run(run_id: 'str') -> 'Run'`: Load one run with all measurements; raises KeyError if unknown.
- `list_runs(experiment_id: 'str', status: 'RunStatus | None' = None) -> 'list[Run]'`: Runs of an experiment ordered by run order, optionally filtered by status.
- `find_run_by_idempotency_key(experiment_id: 'str', key: 'str') -> 'Run | None'`: Find a run by its idempotency key (None if absent).
- `save(result: 'ExperimentResult') -> 'None'`: Persist a whole result (spec, plan, runs, measurements) in one transaction-per-part.
- `get(experiment_id: 'str') -> 'ExperimentResult'`: Load the full ExperimentResult (spec, plan, runs, status); raises KeyError if unknown.
- `save_analysis(analysis: 'AnalysisResult') -> 'None'`: Append an analysis to the experiment's history.
- `list_analyses(experiment_id: 'str') -> 'list[AnalysisResult]'`: Stored analyses, oldest first.
- `save_recommendations(experiment_id: 'str', recs: 'list[Recommendation]') -> 'None'`: Append recommendations to the experiment's optimisation history.
- `list_recommendations(experiment_id: 'str') -> 'list[Recommendation]'`: Stored recommendations, oldest first.
- `save_report(report: 'ExperimentReport') -> 'None'`: Append a report.
- `list_reports(experiment_id: 'str') -> 'list[ExperimentReport]'`: Stored reports, oldest first.
- `record_adapter(metadata, capabilities) -> 'None'`: Record adapter metadata and capabilities used by this database.
- `list_adapters() -> 'list[dict[str, Any]]'`: Recorded adapter metadata and capabilities.
- `enqueue(experiment_id: 'str', run_id: 'str') -> 'int'`: Persist pending work; idempotent per (run, open job).
- `claim(experiment_id: 'str | None' = None, limit: 'int' = 1) -> 'list[tuple[int, str, str]]'`: Atomically claim up to `limit` pending jobs -> [(job_id, experiment_id, run_id)].
- `finish_job(job_id: 'int', state: 'str' = 'done') -> 'None'`: Mark a queued job done or failed.
- `finish_jobs_for_run(run_id: 'str', state: 'str' = 'done') -> 'None'`: Close all open jobs of a run.
- `release_claimed(experiment_id: 'str | None' = None) -> 'int'`: Return claimed (interrupted) jobs to pending, e.g. after a restart.
- `pending_jobs(experiment_id: 'str | None' = None) -> 'list[tuple[int, str, str, str]]'`: Open (pending or claimed) jobs as (job_id, experiment_id, run_id, state).
- `state_log(experiment_id: 'str', run_id: 'str | None' = None) -> 'list[dict[str, Any]]'`: Chronological state transitions for an experiment (or one run).

### `ExperimentRepository`

Minimal snapshot contract (backward compatible with 0.1); implement it to add another storage backend.

- `save(result: 'ExperimentResult') -> 'None'`: Persist a complete ExperimentResult snapshot.
- `get(experiment_id: 'str') -> 'ExperimentResult'`: Load a stored ExperimentResult; raises KeyError if unknown.
- `list_ids() -> 'list[str]'`: IDs of all stored experiments.

### `ExperimentHistory`

Configurations, outcomes, analyses, recommendations and state transitions of one experiment.

- `runs(status: 'RunStatus | None' = None)`: Runs of the experiment, optionally filtered by status.
- `configurations() -> 'list[dict[str, Any]]'`: Every run in order with status, configuration and aggregated outcomes (failed runs are labelled).
- `best_so_far() -> 'list[dict[str, Any]]'`: Trace of the best feasible run (by normalised weighted objective) after each completed run.
- `analyses()`: Persisted analyses, oldest first.
- `recommendations()`: Persisted recommendations, oldest first.
- `reports()`: Persisted reports, oldest first.
- `state_log(run_id: 'str | None' = None)`: Chronological state transitions for the experiment (or one run).

## Reporting

### `ReportEngine`

Assemble :class:`ExperimentReport` from a result and its analysis.

- `generate(result: 'ExperimentResult', analysis: 'AnalysisResult', suggestions: 'list[Recommendation] | None' = None, *, adapters: 'list | None' = None) -> 'ExperimentReport'`: Build an ExperimentReport from a result and analysis (`suggestions` become the optimisation history).
- `build(result, analysis, *, recommendations=None, adapters=None)`: Service-facing wrapper around :meth:`generate`.
- `to_json(report: 'ExperimentReport') -> 'str'`: Stable, human-readable JSON.
- `to_csv(result: 'ExperimentResult') -> 'str'`: One row per run: status, error, configuration, block, feasibility and run-level outcomes.
- `measurements_csv(result: 'ExperimentResult') -> 'str'`: Raw measurements with provenance and quality status (invalid ones included and labelled).
- `effects_csv(analysis: 'AnalysisResult') -> 'str'`: CSV of all treatment and factor-level comparisons with intervals, p-values and evidence labels.

## Extensions

### `PluginRegistry`

Registry of named extension callables.

- `register(kind: 'str', name: 'str', fn: 'Callable[..., Any]', *, replace: 'bool' = False) -> 'None'`: Register `fn` as `name` of `kind`. Refuses silent overwrite.
- `get(kind: 'str', name: 'str') -> 'Callable[..., Any]'`: Return the callable registered under (`kind`, `name`); raises PluginError if absent.
- `has(kind: 'str', name: 'str') -> 'bool'`: True if (`kind`, `name`) is registered.
- `names(kind: 'str') -> 'list[str]'`: Sorted names registered for `kind`.
- `unregister(kind: 'str', name: 'str') -> 'None'`: Remove a registration (no error if absent).
- `metric(name: 'str')`: Decorator registering a derived-metric function.
- `transformation(name: 'str')`: Decorator registering a sample transformation.
- `objective(name: 'str')`: Decorator registering a custom objective function.
- `constraint(name: 'str')`: Decorator registering a custom constraint function.
- `optimizer(name: 'str')`: Decorator registering an optimisation strategy.
- `report(name: 'str')`: Decorator registering a report extension.

## Errors

### `TrialforgeError`

Base class for every error raised deliberately by the SDK.

### `ValidationError`

An experiment definition, configuration or measurement failed validation.

### `DesignError`

A design could not be generated (budget, incompatible method, no feasible runs).

### `AdapterError`

Base class for adapter-originated execution failures.

### `AdapterUnavailableError`

The selected adapter is not registered or reports itself unavailable.

### `CapabilityError`

The adapter lacks a capability required by the requested operation.

### `ExecutionError`

The execution engine could not carry out an operation.

### `InvalidTransitionError`

A lifecycle state transition is not permitted.

### `PersistenceError`

A repository operation failed.

### `AnalysisError`

An analysis could not be performed on the supplied data.

### `OptimizationError`

An optimisation request is invalid or could not be satisfied.

### `PluginError`

A plugin registration or lookup failed.

## Aliases and constants

- `Analyzer` is an alias of `AnalysisEngine`.
- `InMemoryExperimentRepository()` returns an ephemeral `SQLiteExperimentRepository`.
- `DEFAULT_PLUGINS` / `DEFAULT_UNITS`: process-wide default `PluginRegistry` / `UnitRegistry`.
- `API_VERSION`: major version of the public API contract.
